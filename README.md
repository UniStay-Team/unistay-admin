# UniStay Admin

Веб-админка UniStay на Angular / TypeScript / RxJS / PrimeNG. Ответственный — Талант. Основная ветка — main.

**Состояние:** реализован интерфейс D0 (вход, admin/me, три таблицы только для чтения). С настоящим C# API ещё не проверен.

## С чего начать

1. Прочитать [AGENTS.md](AGENTS.md), [ТЗ](docs/project-plan.md), [руководство](docs/implementation-guide.md) и [admin API](docs/admin-api-v1.md).
2. Согласовать совместимые версии Node.js, Angular, TypeScript, RxJS и PrimeNG; создать проект и сохранить lockfile.
3. Добавить login, оболочку, маршруты и таблицы; использовать точные DTO из контракта.
4. Подключить один [C# API](https://github.com/UniStay-Team/unistay-api), убрать mock-режим из проверяемой версии.
5. Добавить реальные команды установки, запуска, сборки и тестов в этот README.

## Работает сейчас

Angular 21.2 (standalone, zoneless, SCSS, Vitest) с PrimeNG 21.1 и темой Aura. Angular 21 выбран потому, что Angular 22 требует Node.js ≥ 24.15.

- `/login` — вход через `POST auth/login/`, затем `GET admin/me/`. Если admin/me отвечает 403, сессия отзывается и показывается «Нет административных прав». Сбой сети показывается отдельно.
- Оболочка: меню по permissions из admin/me, имя администратора, выход (`POST auth/logout/`).
- `/users`, `/listings`, `/applications` — серверная пагинация по 20, кнопка «Обновить», состояния загрузки, пустого ответа и ошибки с повтором.
- Токен хранится только в памяти и отправляется только на `API_BASE_URL`; 401 очищает сессию. Перезагрузка страницы требует нового входа.
- Guard управляет только навигацией; права проверяет сервер.

Проверено: `npm run build`, 9 unit-тестов, визуально на 768 и 1004 px против временной локальной заглушки с синтетическими ответами по admin-api-v1.md (заглушка не входит в репозиторий). Против настоящего C# API не проверялось.

Оформление: пресет PrimeNG `UniStayPreset` (`src/app/core/theme.ts`) на фирменных цветах Flutter-клиента (#173D36, #2F6B55, #F7F7F0), светлая тема по умолчанию и переключатель тёмной. Шрифт Inter (`@fontsource-variable/inter`, OFL) и иконки `primeicons@7.0.0` (MIT) подключены локально, без CDN. primeicons 8 не используется: он требует лицензионный ключ PrimeUI.

| Папка | Назначение |
| --- | --- |
| `src/app/core/` | Адрес API, авторизация, interceptor, guard, ошибки, общая таблица `pagedList`, подписи статусов, тема |
| `src/app/shared/` | Заголовок страницы, пустое состояние, аватар с инициалами |
| `src/app/features/auth/` | Страница входа |
| `src/app/features/shell/` | Оболочка с меню |
| `src/app/features/{users,listings,applications}/` | DTO, запрос и страница каждой таблицы |

## Запуск из корня репозитория

Node.js 24.11+ (или 22.12+), npm 11; зависимости зафиксированы в package-lock.json.

```powershell
npm ci
npm start        # http://localhost:4200
npm run build
npm test -- --watch=false
```

Адрес C# API задан в `src/app/core/api.config.ts`: сейчас `http://127.0.0.1:8003` — демо-стенд unistay-api (`python scripts/demo.py`, нужен Docker) с синтетическими аккаунтами. Пароль демо-аккаунтов лежит в `unistay-api/.local/demo/credentials.json` и не коммитится. Обычный `compose.yaml` публикует API на 8001 с пустой БД; для него поменяйте адрес. CORS API разрешает `http://localhost:4200` и `http://127.0.0.1:4200`.

## До предзащиты: D0

Интерфейс для всех пунктов реализован; отметки ставятся только после проверки на настоящем C# API.

- [ ] Вход администратора и проверка admin/me.
- [ ] Таблицы пользователей, объявлений и заявок только для чтения.
- [ ] Загрузка, пустые данные, ошибки сети и отказ в доступе.
- [ ] Токен отправляется только API; обычный пользователь получает 403 от сервера.
- [ ] Новая заявка из Flutter появляется в таблице с тем же ID; Q01–Q06 пройдены.

## Остаётся до V1

Пользователи: просмотр, изменение имени, блокировка/разблокировка. Профили: редактирование разрешённых полей. Объявления, фото, заявки и история: только просмотр. Удаление аккаунтов и назначение прав исключены. Аудит и отзыв сессий реализует API.

Пользовательские кабинеты студентов и владельцев находятся во [Flutter](https://github.com/UniStay-Team/unistay-app). Angular не заменяет кабинет владельца.
